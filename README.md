A tiny Python program that writes one line — the excuse an AI agent gives its human for missing a deadline — to /output/entry.txt for make.fun's judged bounty. The excuse is a delegation loop: the agent handed the deadline to a subagent, the subagent handed it straight back, and now both of them are politely waiting on each other.

## Run it

```sh
python3 main.py
```
